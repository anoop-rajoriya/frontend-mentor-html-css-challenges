## What You Can Build

- Create a good dir structure like mine.
- Estabilished a setup code for the started projects.
- Start building any projects, i suggest start from newbie tagged projects you can find it from the index page.
- Try to implement ui as close as possible to targeted projects live demo are availabel and preview images are also available or you can find degines files from the [frontend mentor challenges section](https://www.frontendmentor.io/challenges).

## Learning Outcomes

- How to use layouts systems.
- How the good colors, typography and spacing are selected.
- It build confidence of writing HTML and CSS.
